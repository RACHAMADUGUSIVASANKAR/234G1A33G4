# Smart Notification Dashboard

## Project Overview

Smart Notification Dashboard is a React-based frontend application that consumes the Affordmed Notification API.

The application allows users to:

- View notifications
- Search notifications
- Filter notifications
- Display top priority notifications

---

## Technologies Used

- React
- Vite
- Axios
- JavaScript

## Installation

Clone repository:

git clone <repository-url>

Install dependencies:

npm install

Run application:

npm run dev

---

## Features

### Notification Listing

Displays all notifications from API.

### Search

Search notifications by message.

### Filtering

Filter notifications by:

- Placement
- Result
- Event

### Priority Ranking

Top notifications are displayed based on calculated priority score.

### Activity Tracking

Application events are logged for monitoring.
